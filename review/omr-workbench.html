如何阅读 OMR Tokens

每行通常描述元信息、小节边界或一个节奏事件。同一行中出现多个 N_ 音符时，代表它们在同一拍同时发声。

元信息与结构

TEMPO_70
速度为每分钟 70 拍；数字部分是 BPM。
TS_4_4
4/4 拍；前一个数字是每小节拍数，后一个是拍值。
BAR / END_BAR
一个小节的开始与结束。
BEAT
一个节奏事件；后面继续描述时值、音符和技巧。

节奏

DUR_4 / 8 / 16
四分、八分、十六分音符；数字是时值分母。
DOTS_1 / DOTS_2
一个或两个附点。
TUPLET_3_2
三音占两音时值，也就是常见的三连音关系。
REST
休止符；这一拍没有发声音符。

音符

N_S3_F4
第 3 弦、第 4 品。S 表示弦，F 表示品位。
N_S2_FX
第 2 弦的闷音或死音；FX 中的 X 表示没有明确品高。
多个 N_…
同一 BEAT 中的多个音符，表示和弦或同时发声。

技巧

NTECH_BEND_1…8
推弦技巧的 8 个离散值。
NTECH_TIE_START / DEST
延音线的起点与终点。
NTECH_SLIDE_IN_1 / 2
从下方或上方滑入当前音。
NTECH_SLIDE_OUT_1…4
换把滑音、连奏滑音、向上滑出或向下滑出。
NTECH_VIBRATO_1 / 2
普通揉弦或宽揉弦。
NTECH_LEGATO_ORIGIN
击弦或勾弦连奏关系的起点。
NTECH_HARMONIC_…
泛音类型；后缀区分自然、人工、捏泛音等。
NTECH_HARMONIC_VALUE_12
泛音的数值参数；含 P 时表示小数点，例如 14P7 表示 14.7。
NTECH_GHOST
幽灵音或弱化处理的音符。
BTECH_ARPEGGIO / STRUM
琶音与扫弦，后缀 DOWN / UP 表示方向。

模型完整范围：在 models/guitar-tab-omr/vocab.json 搜索 NTECH_ 和 BTECH_。若 token 已存在但预览提示“暂未转换”，再检查本页的 techniqueToAlphaTex 映射。
