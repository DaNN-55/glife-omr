1. 先完成当前步骤的必要材料；缺少样本时可先开发基础能力，用人工可判定的小例子检查，不宣称真实效果已验证。
2. 每一步按文档中的“完成条件”记录证据。代码实现、自动检查、真实谱面验收分别记录。
3. 结构通过、结果一致、能播放或能导出，都只是候选结果的性质；正确性来自与原谱真值的比较。
4. 保存人工审核会更新当前工作台的训练候选，但不会训练模型。测试样本的隔离按 B1 的来源与用途清单执行。
5. 复用当前 tokens 审核流程；旧 `golden-001` 多级 Review Decision 链已退役，不能作为新系统的设计基础。
6. 无法确定的原谱写为待确认；当它阻塞当前步骤时，向用户指出具体样本、小节及疑点。选择参数、文件名等可逆实现细节由执行者处理并记录。
